# Django Homework Project

Учебный проект по Django для выполнения домашних заданий.

## Описание

Проект представляет собой каталог товаров с базовой функциональностью:
- Главная страница с отображением товаров
- Страница контактов
- Административная панель для управления содержимым

## Технологии

- Python 3.x
- Django 4.2+
- Bootstrap 5
- PostgreSQL (будет добавлено в ДЗ2)
